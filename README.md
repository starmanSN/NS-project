# Проект тестового задания

Для выполнения задания были немного расширен функционал. В частности, средства разворачивались не локально, а на удаленных серверах.

```
Инстанст БД: 185.154.52.218:5432/n_project

Брокер Кафки: - 185.154.52.222:9092

Grafana: http://31.76.225.70:3000 user vire/view

VictoriaMetrics: http://31.76.225.70:8428
```

Нагрузочный скрипт реализован на jmeter, сам скрипт размещен в директории с соответствующим названием.

Изменение задержки после вычитки из Кафки и записи в БД реализовано через контроллер путем отправки запроса по адресу ```curl -X PUT "http://localhost:8080/api/delay?ms=3000```
